# 配置面板

安装后 Cursor 活动栏会出现 MyCursor 图标，点开就是 provider 配置界面。这是日常唯一需要打开的地方——加 provider、贴密钥、拉模型、存盘，模型随即出现在 Cursor 的模型选择器里。

## 一、一条命令装完

```bash
npx . install
```

这一条命令做四件事：

1. 给本机所有 Cursor 安装打补丁（含 `~/.cursor-server` 远端）
2. 从你自己的 Cursor 里提取 protobuf schema
3. 把面板打包成 VSIX 并通过 Cursor 官方 CLI 安装
4. 写好默认配置

重启 Cursor 后，服务由扩展自动拉起（`mycursor.server.autoStart`，默认开），面板可用。

想跳过面板只做打补丁：`npx . install --skip-extension`。
单独装/卸面板：`npx . extension` / `npx . extension --remove`。

### VSIX 是自己打的，不依赖 vsce

VSIX 就是特定布局的 ZIP。为此引入 `@vscode/vsce` 会带进一棵很大的依赖树，而本工程运行期是零依赖的，所以 `packages/patcher/src/vsix/` 里写了一个最小 ZIP 写入器（deflate + CRC32 + 中央目录）和 VSIX 清单生成器。

装入方式走 Cursor 自己的 CLI（`cursor --install-extension … --force`），所以它落在**用户扩展目录**，和任何其他扩展一样可禁用、可卸载。它**不会**被塞进 Cursor 的内置扩展目录——那需要绕过扩展签名校验，是比"前置一段载荷"侵入性大得多的改动。

打包内容是在扩展 `package.json` 的 `vsix.include` 里**显式列出**的，不是靠排除规则推导的：

```jsonc
"vsix": {
  "name": "mycursor",          // VSCode 扩展 id 不能带作用域前缀
  "include": ["package.json", "dist/extension.cjs", "dist/server/launch.js", "media/**", "resources/**"]
}
```

成品 9 个文件、68 KiB。

## 二、界面

### 顶部状态

三个状态芯片，都可点：

| 芯片 | 含义 | 点击 |
|---|---|---|
| BYOK | 总开关状态 | 切换 BYOK 模式 |
| Server | 本地服务在线与版本 | 重启服务 |
| Schema | 已加载的 Cursor 协议 schema 版本 | 仅展示；灰/黄表示未提取，此时无法注入模型 |

### Provider 表单

| 字段 | 说明 |
|---|---|
| Name | 显示名 |
| Type | `openai-chat` / `anthropic-messages` / `gemini-generate`。按端点协议命名而非厂商，因为同一协议服务很多家 |
| Base URL | 留空则用该类型的默认地址，占位符会显示默认值 |
| Auth Value | 密钥，默认掩码，可点 ◎ 显示 |
| Proxy URL | 可选。HTTPS 走 CONNECT 隧道，零依赖实现 |
| Custom Headers | 可选 JSON，例如 `{"anthropic-beta": "context-1m-2025-08-07"}`。格式非法时输入框标红但不阻断编辑 |

### 模型

`↓ Fetch` 向该 provider 拉取它实际提供的模型列表；`+ Add Model` 手动加一条。

每个模型：

| 控件 | 落到 Cursor 的哪个字段 |
|---|---|
| API Model | `server_model_name`（发往上游的名字）。输入框带**模糊搜索**，在 Fetch 回来的目录里按子序列匹配——输 `g41` 能选中 `gpt-4.1` |
| Display Name | `client_display_name` / `inputbox_short_model_name` |
| Agent | `supports_agent`；关掉则 `is_chat_only` 置位 |
| Images | `supports_images` |
| Cmd+K | `supports_cmd_k` |
| Fast | 快速变体标记 |
| Thinking + 等级 | `supports_thinking`，等级用于发往上游的推理强度 |
| Context Token Limit \* | `context_token_limit` / `auto_context_max_tokens` |
| Max Output Tokens \* | 发往上游的输出上限 |
| Off | 关掉则该模型不参与注入 |
| Tooltip Markdown | `tooltip_data.markdown_content`，在模型选择器里悬停可见 |

带 `*` 的两项必填，留空或非正数时输入框标红。

### QuickSwitch Options

折叠区，对应 Cursor 模型选择器里模型旁边的快捷切换，会生成 `ModelParameterDefinition`：

- **Reasoning Levels**：勾选允许循环切换的推理等级，生成 `reasoning_effort` 枚举参数（可用快捷键循环）
- **Context Options**：逗号分隔的上下文档位，生成 `context_size` 枚举参数
- **Fast Toggle**：生成 `fast` 布尔参数

### Web Search

Provider 列表上方的一张独立卡片。Cursor 自己的网络搜索跑在它的后端上，接管后会失效，这里配的是本地服务提供的替代品（机制见 [网络搜索.md](网络搜索.md)）。

- **Backend**：DuckDuckGo / Exa / Tavily / Brave / Jina Reader / Firecrawl
- **API Key**：**只在需要注册的后端上显示**。给不需要注册的 DuckDuckGo 摆一个空的必填框，会让本来能用的默认配置看起来没配完
- **Max Results** / **Proxy URL** / **Also offer web_fetch**

默认关闭。这一块写进 `config.json` 而不是 `providers.json`，但用户是在同一个表单里改的，所以**一次 Save 同时落两个文件**。

### 底部

`+ Add Provider` / `Reset` / `Save`。有未保存改动时 Save 会带一个圆点。

## 三、编辑模型：草稿直到按下 Save

界面上的编辑只改内存草稿，**不落盘**。这是有意的：服务会监听 `providers.json`，如果边打字边写盘，一个打到一半的密钥或上下文长度就会被正在运行的服务读走。

按 Save 才写入，写入后面板重新从磁盘读一遍并刷新——所以手工编辑过的文件和面板永远不会各说各话。`Reload` / `Reset` 都是重新从磁盘读。

## 四、安全边界

- 面板用 VSCode 的 webview 沙箱，**每次加载生成一次性 nonce**，CSP 为 `default-src 'none'`，不允许 `unsafe-inline` 也不允许 `unsafe-eval`
- 样式与脚本作为 webview 资源加载，`localResourceRoots` 限定在扩展的 `media/` 下
- **密钥不进 webview 的网络路径**：`↓ Fetch` 由扩展宿主发起，webview 只拿到模型列表
- 所有状态存在 `~/.mycursor/providers.json`，不写进 VSCode 的 globalState

## 五、验证

`pnpm verify:panel` 用桩化的 `vscode` 模块激活**真实的扩展包**，断言 46 项：注册侧边栏视图、渲染出的 webview 文档带 nonce 且 CSP 收紧、表单包含规格里的每个字段、从磁盘读到 provider、能力与 QuickSwitch 选项往返不丢、保存后落盘且服务端 registry 能直接读、一次 Save 同时写出 `providers.json` 与 `config.json` 的 `webSearch` 且不破坏配置里的其余部分。

这一套不需要启动 Cursor，所以每次改动都能跑。详见 [验证报告.md](验证报告.md)。
